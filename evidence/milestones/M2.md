# M2 — Data and forms conformance

Completed 16 October 2026. T026–T046 implementation is committed task by task.

The seeded race property suite ran 500 request schedules with fast-check seed `20261016`. Each schedule shared one GET flight between two subscribers, varied completion and owner/generation/key/epoch/invalidation state, and asserted that only current subscribers accepted the result. It recorded both accepted and discarded outcomes and required the flight map to empty. Companion integration cases checked TTL 0/1000 consumers, null success, cache eviction and invalidation, distinct timeout 100/1000 flights, and a replaced mutation whose canceled client still left two server-side writes recorded. See [tests/integration/data-forms.spec.ts](../../tests/integration/data-forms.spec.ts).

The native browser matrix covered model controls and IME, successful-control encodings and files, validation and actual submitters, debounce snapshots, reset, server field errors and ARIA, pending busy counts, external submit buttons, form failure preservation, and explicit reset. The full suite passed 273/273 across Chromium, Firefox, and WebKit, including six M2 parity/leak checks. A classic/ESM production-bundle fixture produced identical form, model, action, and request-body results. Unmount during simultaneous pending GET and POST work yielded zero owners, timers, listeners, state subscribers, pending actions, cache entries, and queued jobs in the inspector; the route responses were released afterward without further commits.

Validation commands: `npm run typecheck`, `npm run build`, `npm run test:unit`, `npm run test:conformance`, `npx vitest run tests/integration/data-forms.spec.ts`, `npm run test:browser`, and `npx playwright test tests/browser/data-forms-conformance.spec.ts`. The conformance suite's response-order harness now waits for the first accepted completion before releasing the second barrier, avoiding a transport-order assumption unrelated to framework behavior.

An uncertain client-side mutation is reconciled through an authoritative GET before retry; the example is [action-reconcile.md](../../examples/action-reconcile.md).
