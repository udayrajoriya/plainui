# M4 — Fragments and UI conformance

Completed 16 October 2026.

The M4 browser matrix covers the exact fragment sanitizer allowlist, Trusted Types isolation, transactional target arbitration, all six swap modes, focus ownership, native dialogs, text-only toasts, tabs keyboard behavior, optional responsive styles, and Chart.js/CodeMirror behavior cleanup. The combined hybrid scenario includes product cards, checkout form controls, an HTML order-summary destination, a native dialog, tabs, a toast region, and a Chart.js behavior. It exercises twenty rapid route commits, competing fragment generations, mutation invalidation, dialog removal, and widget disposal. Every owned route, timer, listener, fragment candidate, dialog, toast, tab controller, and chart instance is released at teardown.

The CSS-free keyboard scenario activates tabs using arrow and Enter keys and completes an automated axe scan with zero violations. Default untrusted fragments remove directives and executable subtrees. Explicitly enhanced developer templates retain only their permitted binding directives. Manual assistive-technology qualification remains assigned to T092.

Security evidence at this gate is 15 fragment-policy cases passing in Chromium, Firefox, and WebKit, with zero forbidden effects and zero beacons. The hybrid and extension lifecycle suites pass in the same three engines; the extension suite performs 100 Chart.js and CodeMirror mount/update/unmount cycles per engine and returns to its baseline.

Deterministic gzip measurements use Node zlib level 9 with mtime 0. The classic files measure: core 48,835 bytes, router 5,144 bytes, fragments 14,235 bytes, and UI 5,951 bytes, for 74,165 bytes combined. ESM measures: core 48,647 bytes, router 5,111 bytes, fragments 14,194 bytes, and UI 5,925 bytes, for 73,877 bytes combined. Chart.js and CodeMirror are example-only and excluded. The current implementation exceeds the 35,840-byte core budget by 12,995 bytes and the 71,680-byte combined budget by 2,485 bytes in the larger classic variant. This is an explicit unresolved release gate. Required behavior and sanitizer protections remain intact; T094 must profile and reduce the production bundles or propose a transparent numerical specification revision before release qualification.
