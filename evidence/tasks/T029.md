# T029 — Fetch transport and response decoding

Completed 15 October 2026. Commit: recorded in Git history as the T029 commit.

One Fetch attempt now uses the validated draft with `redirect: 'error'`, credentials, and a linked abort controller. Its deadline spans fetch and the single response body read, then is cleared before adapter hooks. Caller cancellation remains an AbortError; deadline expiry is a timeout error. Opaque/redirected responses are rejected. Empty 2xx responses decode to null; nonempty JSON requires an application/json or application/*+json media type and safe JSON normalization. Non-2xx responses remain HTTP errors, with valid JSON error bodies available to adapter error hooks and other bodies withheld. HTML mode requires text/html and an external fragment handler. Response metadata omits Set-Cookie and bounds the request ID.

Validation: typecheck, build, and seven transport unit cases covering empty bodies, whitespace and media types, redirect policy, single body consumption, HTTP errors, timeout versus cancellation, body-read deadlines, and HTML delegation.
