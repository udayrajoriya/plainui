# T044 — Server field errors and accessibility associations

Completed 16 October 2026. Commit: recorded in Git history as the T044 commit.

Field-error presenters are scoped to their nearest action form and indexed by literal control name, including externally associated controls. A normalized failure displays the first message with `textContent` while the action record retains every message. Presenter IDs are document-unique; matching controls receive additive `aria-describedby` tokens and owned `aria-invalid`. Editing one field removes only that field's entry and claims. New submits and resets clear prior associations, and cleanup preserves later author changes. An authored summary pattern for global and unmatched field errors is in `examples/form-error-summary.md`.

Validation: typecheck, build, 122 unit tests, and fifteen browser cases across Chromium, Firefox, and WebKit, covering literal names, external controls, full records, edit/reset behavior, outside-form rejection, author-owned ARIA/text cleanup, and axe audits.
