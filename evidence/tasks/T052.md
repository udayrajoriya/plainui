# T052 — Component instance lifecycle and custom events

Completed 16 October 2026. Commit: recorded in Git history as the T052 commit.

Component instances preserve their authored custom host, allocate isolated component scopes, connect props without reinitializing local state, clone and rewrite definition content, project caller-owned slots, mount nested registered components, and dispose nested instances and releases exactly once. Preparation failures retain authored fallback content. Recursion is bounded at 128 ancestors. Custom component events require lowercase nonreserved names and dispatch bubbling, composed JSON details from the host; custom host handlers remain caller-owned.

Validation: typecheck and twelve browser cases across Chromium, Firefox, and WebKit covering isolation, host preservation, nested cleanup, caller events, recursion, and missing/schema fallback behavior.
