# T013 — State cells and dependency tracking

Completed 14 October 2026. Commit: recorded in Git history as the T013 commit.

State cells deep-copy JSON defaults, retain immutable source/writability metadata, and increment versions only when the written primitive or object identity changes. `StateStore` reads and writes through parsed paths, records exact path dependencies, supports whole-object, length, and iteration read kinds, replaces successful dynamic dependency sets while retaining the old set after failure, and batches invalidations while writes remain synchronously visible. Thenable-returning batch callbacks throw `BATCH_ASYNC` after any synchronous writes have committed. Disposed scopes reject writes.

Validation: `typecheck`; 48 unit tests. New cases cover immediate reads, one notification per batch, parent-child invalidation, sibling no-op, branch replacement, failure recovery, asynchronous batch rejection, disposed writes, and copied defaults.
