# T035 — Session reset and public resource refresh

Completed 15 October 2026. Commit: recorded in Git history as the T035 commit.

The app advances its authentication epoch before clearing root-local flights, cache, invalidation state, and resource records. Late adapter results cannot commit across reset. Reset leaves declared local/store/persisted state intact and does not issue a new request; an explicit refresh after credentials change can restart. Public refresh resolves lexical or app-scoped resources, coalesces concurrent calls, bypasses settled cache, and waits for the binding flush. Incomplete URLs reject with RESOURCE_SUSPENDED, while disposal, supersession, and reset cancel the operation. [The logout example](../../examples/session-logout.js) shows the required reset-before-sign-out order.

Validation: typecheck, build, unit tests, and focused resource browser tests across Chromium, Firefox, and WebKit, including late adapter and reset races.
