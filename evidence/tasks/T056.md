# T056 — Guard preparation and cancellation

Completed 16 October 2026. Commit: recorded in Git history as the T056 commit.

Navigation preparation now allocates monotonically increasing generations, aborts the previous preparation, resolves and freezes the destination before guards, and runs guards sequentially with frozen `from`, `to`, and signal context. Explicit false cancels silently; throws and rejections diagnose `GUARD_ERROR`. Every await rechecks generation and liveness, so superseded or unmounted work cannot produce a prepared transaction or mutate URL/DOM. Guard unregister and disposal are idempotent.

Validation: focused unit coverage plus browser assertions for ordering, sync/async cancellation, rejection, latest-wins, unmount, and zero DOM changes before commit.
