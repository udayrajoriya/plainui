# T032 — Bounded resource cache and invalidation generations

Completed 15 October 2026. Commit: recorded in Git history as the T032 commit.

The root-local settled-value cache retains immutable data snapshots in bounded LRU order. Reads apply each consumer's TTL at its exact boundary and require matching epoch and invalidation generation. Capacity zero retains nothing. Key invalidation evicts the entry, advances the generation, marks every attached active consumer stale, cancels older work, and schedules automatic consumers. Concurrent explicit refresh calls share the latest revalidation outcome; mutation invalidation supersedes it.

Validation: typecheck and 98 unit tests, including new LRU, TTL, zero-capacity, invalidation, and refresh-coalescing cases.
