# T018 — Value and attribute sinks

Completed 14 October 2026. Commit: recorded in Git history as the T018 commit.

The binding sinks use `textContent` for primitive text, reject object/array text, enforce the shared bind allowlist, write `value` and `checked` as properties, handle boolean and ARIA attributes separately, and remove null values. URL writes resolve against the owning document and reject unsafe schemes, removing a previously installed URL on rejection. Class bindings retain initial static tokens while owning only dynamic tokens. Show bindings toggle `hidden` and skip equal writes. The App's initial binding pass evaluates expressions, records dependencies, re-renders on state writes, emits local diagnostics, and removes cloak only after successful work.

Validation: `typecheck`; three browser sink cases across Chromium, Firefox, and WebKit, plus the startup integration cases from T017. Cases cover literal HTML text, object rejection, boolean/ARIA behavior, URL rejection, class ownership, and no-op show writes.
