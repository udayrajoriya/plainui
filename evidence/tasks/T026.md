# T026 — URL templates and query maps

Completed 15 October 2026. Commit: recorded in Git history as the T026 commit.

The URL compiler separates literal text from balanced expression regions, rejects unmatched raw braces, and parses expressions with the core grammar. Resolution refuses scheme and authority substitutions, percent-encodes each scalar as one component, suspends on null, resolves request and navigation URLs against their separate bases, strips request fragments, and validates protocol, userinfo, and allowed origins. Query maps replace all literal pairs for supplied keys while retaining the order of unrelated and repeated pairs; nested values are rejected.

Validation: typecheck, build and five focused unit cases covering encoded slashes, null suspension, query replacement, authority/credentials/protocol rejection, encoded literal braces, relative paths, and navigation base resolution.
