# T064 — Fragment action compilation and target arbitration

Completed 16 October 2026. Commit: recorded in Git history as the T064 commit.

The fragments module now installs a root runtime, compiles the six swap modes with the documented defaults, validates target and enhancement policy before transport, sets the HTML accept header, and requires successful `text/html` responses. Target resolution enforces the initiating app root, connectivity, ignore boundaries, and optional ownership prohibitions. A target-owner keyed arbiter advances generation at accepted trigger time, aborts superseded work shared by different actions, links target lifetime cancellation, and prevents detached targets from accepting work. Resource HTML directives are rejected.

Validation: all seven named acceptance cases ran in Chromium, Firefox, and WebKit (21 passing cases), and the workspace TypeScript check passed.
