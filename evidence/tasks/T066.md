# T066 — Transactional fragment swaps

Completed 16 October 2026. Commit: recorded in Git history as the T066 commit.

The fragments package now commits inner, outer, append, prepend, before, and after candidates behind one precommit gate covering action/target life, target generation, epoch, connectivity, and ownership policy. Inner and outer use explicit disposal hooks; the four insertion modes create releasable anchored ranges linked to destination lifetime. Stable insertion boundaries preserve accepted order. Attachment, activation, resource invalidation, and ref registration occur after the single mutation transaction. A stale candidate is discarded without mutation, while an unexpected activation failure installs fixed local alert text and emits `FRAGMENT_ACTIVATION`.

Validation: all seven named swap cases passed in Chromium, Firefox, and WebKit (21 passing cases), including every swap mode, lifetime cleanup, ordering, stale rejection, local activation recovery, and a single observer callback.
