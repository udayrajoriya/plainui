# T027 — Request drafts and final policy

Completed 15 October 2026. Commit: recorded in Git history as the T027 commit.

Request drafts now carry method, canonical URL, credentials, response mode, timeout, retry, adapter identity, epoch, generation and owner signal, with transport body and header values held privately. App and endpoint headers merge case-insensitively with null deletion and reject browser-controlled names, invalid values, symbols and accessors. JSON and form bodies get their required content type; multipart leaves the browser boundary unset. Adapter preparation receives a detached candidate and the result is revalidated for method, URL/origin, credentials, body and policy. CSRF is read only after preparation, overrides conflicting values for same-origin unsafe methods, and is removed cross-origin.

Validation: typecheck, build, and six focused unit cases covering case/null headers, forbidden fields, post-prepare origin validation, late CSRF, missing/cross-origin token behavior, and multipart boundary handling.
