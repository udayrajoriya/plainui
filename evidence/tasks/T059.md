# T059 — Route titles, focus, scroll, and hash anchors

Completed 16 October 2026. Commit: recorded in Git history as the T059 commit.

Route commits evaluate `ui-title` against the published route context, preserve absent titles, and map null to an empty title. After the route flush, focus moves to the first connected `h1` or the outlet with temporary `tabindex=-1`, then restores the author state on blur/disposal. New navigation scrolls to top, traversal restores indexed coordinates, and a decoded in-route hash ID takes precedence through `getElementById`. Superseded post-flush work is canceled and resource-only refreshes do not rerun focus or scroll.

Validation: nine browser cases across Chromium, Firefox, and WebKit cover title expressions, both focus targets, top/restored/hash scrolling, tabindex cleanup, supersession, and stable shell focus.
