# T065 — Detached fragment candidates

Completed 16 October 2026. Commit: recorded in Git history as the T065 commit.

Fragment responses can now be prepared as detached, releasable candidates. Preparation sanitizes before validation; applies enhanced-content restrictions; checks retained ref and document ID conflicts while excluding nodes scheduled for replacement; enforces the one-element outer-swap rule; requires the same explicit ref for enhanced outer swaps; and records an untrusted outer ref as sidecar metadata. Validation callbacks run against detached DOM with an abort signal, and preparation never changes the live destination or starts runtime effects.

Validation: all seven named candidate cases passed in Chromium, Firefox, and WebKit (21 passing cases), including duplicate refs/IDs, forbidden directives, outer cardinality and ref handling, no-side-effect preparation, and failure preservation.
