# T016 — Directive compilation

Completed 14 October 2026. Commit: recorded in Git history as the T016 commit.

The compiler walks elements and template content, canonicalizes `data-ui-*` spellings while retaining source names, validates directives with the shared schema, and stages accepted nodes into scope, declaration, structure, component, value, event, behavior, and resource phases. It captures inert template source for later instantiation. Invalid local nodes retain their authored DOM and receive no plan; ignored descendants and declaration templates are not traversed. Root directive configuration issues are flagged as fatal.

Validation: `typecheck`; six focused browser cases across Chromium, Firefox, and WebKit. They cover aliases, duplicate spellings, unknown directives, nonempty flags, placement, ignore boundaries, local fallback, and template capture.
