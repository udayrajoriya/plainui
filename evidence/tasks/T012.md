# T012 — Owners, ranges, and disposal

Completed 14 October 2026. Commit: recorded in Git history as the T012 commit.

`OwnerTree` allocates monotonic owner IDs per root and indexes owned DOM nodes in a WeakMap. Disposal marks the complete lifetime closure inactive, aborts signals, cleans child owners before parents, invokes each disposer once in reverse registration order, isolates cleanup exceptions, removes owned ranges, and releases index entries. Lifetime links reject cycles. Range insertion and moves use comment anchors and document fragments, enforce root/ignore boundaries and anchor consistency, and restore focus after a move.

Validation: `typecheck`; six browser cases across Chromium, Firefox, and WebKit. These cover child-before-parent, connected cleanup, double disposal, throwing cleanup, abort reentrancy, focus-preserving moves, broken anchors, and zero live owners after unmount.
