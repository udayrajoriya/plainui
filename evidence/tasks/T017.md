# T017 — Root startup and distribution

Completed 14 October 2026. Commit: recorded in Git history as the T017 commit.

`PlainUI.create()` and `PlainUI.mount()` now create an App with the C03 lifecycle and a synchronous mount return. A document-local symbol registry enforces root/name uniqueness across runtime copies. Classic boot discovers roots once after DOM readiness; ESM does not auto-discover. Mount validates configuration, compiles plans, builds owner and lexical scope trees, declares state/store cells, schedules initial value bindings, and waits for bounded same-origin imports before resolving `ready`. Independent bindings flush while imports load. A successful binding removes that element's cloak; failed bindings leave it in place with diagnostics. Unmount is synchronous, idempotent, aborts imports, and rejects pending readiness. Official module installation remains limited to the created state.

Validation: `typecheck`, production/development `build`, 53 unit tests, and 15 startup browser cases across Chromium, Firefox, and WebKit. Cases cover classic and ESM boot, nested/duplicate roots, repeated mount, first binding readiness, import wait and unmount, and one-pass classic discovery.
