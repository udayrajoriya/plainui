# T028 — Adapters and normalized errors

Completed 15 October 2026. Commit: recorded in Git history as the T028 commit.

The data adapter registry installs identity version 1, validates custom names and versions, rejects duplicates, and can freeze before use. Prepare, success, and error hooks run against detached read-only context and response metadata. Every hook checks signal and generation before and after awaits, uses its own deadline, and clears timers and abort listeners. Stale completions become cancellation. Hook throws, invalid JSON, and invalid mapped errors become fixed safe adapter failures. Normalized errors have exactly kind, status, code, message, fields, retryable, and requestId; timeout is an adapter error with `ADAPTER_TIMEOUT` and no retry.

Validation: typecheck, build, and six adapter unit cases covering identity/version, envelope transformation, validation mapping, stale async completion, invalid output and throws, and deadline expiry.
