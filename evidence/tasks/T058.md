# T058 — Route scopes and outlet ownership

Completed 16 October 2026. Commit: recorded in Git history as the T058 commit.

Route views preclone and precompile destination templates before disposal, mark one exclusive router-owned outlet, abort and release the old route, publish the new frozen route, allocate a fresh scope for every commit including same-pattern parameter changes, and activate the destination as one commit. Shared shell nodes remain untouched. Resource startup is queued after visible binding activation, while view disposal aborts the old route and releases the outlet claim.

Validation: browser cases across Chromium, Firefox, and WebKit cover fresh scopes, shell preservation, nonblocking resources, old-request abortion, and exclusive outlet ownership.
