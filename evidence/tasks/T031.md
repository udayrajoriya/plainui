# T031 — Request keys and shared in-flight GETs

Completed 15 October 2026. Commit: recorded in Git history as the T031 commit.

The data package computes length-prefixed cache identities from root, epoch, adapter, method, canonical URL, credentials, and a SHA-256 digest of the effective headers. It uses Web Crypto in secure contexts and the pinned noble fallback otherwise. A root-local coordinator shares compatible GET operations, separates retry and timeout policies, cancels transport only when the last subscriber leaves, rejects stale generations, and isolates subscriber callback failures. Settled flights are removed.

Validation: typecheck, package-boundary check, build, and 93 unit tests including six new key/flight cases.
