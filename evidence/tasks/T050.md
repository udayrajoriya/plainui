# T050 — Slot projection with caller scopes

Completed 16 October 2026. Commit: recorded in Git history as the T050 commit.

The slot pipeline parks original host children with their caller scope and source-order metadata, assigns literal named/default groups, and rejects meaningful unmatched content or duplicate placeholders. Projection replaces placeholders with comment-anchored ranges. Assigned nodes compile through the caller scope; fallback nodes compile through the component scope. Movement is reported to the ownership journal hook, each node is compiled once, and disposal releases all projected/fallback bindings without disposing unrelated caller state.

Validation: typecheck, build, 122 unit tests, and twelve slot browser cases across Chromium, Firefox, and WebKit for scope routing, named order, fallback, unmatched content, duplicate placeholders, whitespace, single compilation, and listener cleanup.
