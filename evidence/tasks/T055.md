# T055 — Router installation and eligible navigation

Completed 16 October 2026. Commit: recorded in Git history as the T055 commit.

The router module now installs a per-App runtime through the official module bridge, claims sole document router ownership, validates routes/outlet without compiling inactive templates, selects the initial deep link after application readiness, and releases its claim and delegated listener on unmount. Delegated links intercept only unmodified primary same-origin HTTP(S) navigation within the configured base path. Native hash links, downloads, external targets, unmarked anchors, modified/middle clicks, and external schemes retain browser behavior. Command navigation rejects cross-origin targets and classifies same-origin destinations outside the router base for document navigation.

History-mode deployments must configure the host to return the application document for document requests beneath `basePath`; asset and API misses must retain their normal status responses.

Validation: typecheck and router installation/link browser cases across Chromium, Firefox, and WebKit.
