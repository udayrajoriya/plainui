# T020 — Keyed list reconciliation

Completed 15 October 2026. Commit: recorded in Git history as the T020 commit.

The loop parser captures `item[, index] in expression` without splitting expression arguments and rejects reserved, repeated, or malformed aliases. The keyed reconciler evaluates all keys before touching live DOM, uses type-preserving string/finite-number Map keys, normalizes `-0` to `0`, and rejects duplicates atomically. It prepares new item owners, disposes removed items, moves retained anchored ranges right-to-left, and publishes read-only item/index aliases so retained scopes and local state survive replacement. Focus survives range moves; removing a focused item moves focus to the list container with a temporary `tabindex` removed on blur. Null and empty arrays clear the list.

Validation: `typecheck`, `build`, 55 unit tests, and three keyed-list browser cases across Chromium, Firefox, and WebKit. Cases cover parser aliases, reorder identity and focus, item replacement, duplicate-key atomicity, empty removal, and focus fallback.
