# T049 — Literal and reactive props

Completed 16 October 2026. Commit: recorded in Git history as the T049 commit.

Prop compilation matches declared names exactly, including kebab case. Literal attributes are accepted only for string props; `ui-prop-*` expressions supply typed values. Both forms together, missing required props, unknown prop-like host attributes, and nonmatching values are rejected. Defaults are detached per instance, and nested values are frozen before publication into readonly component cells. Caller-side subscriptions update only the affected prop; an invalid update diagnoses and preserves the last valid value without reinitializing local state. All subscriptions release on instance abort/disposal.

Validation: typecheck, build, and twelve focused browser cases across Chromium, Firefox, and WebKit for literals, typed expressions, required and duplicate forms, defaults, nested readonly values, kebab names, invalid updates, and cleanup.
