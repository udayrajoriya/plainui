# T037 — Action debounce and concurrency

Completed 15 October 2026. Commit: recorded in Git history as the T037 commit.

The action operation controller captures a detached input snapshot, uses a trailing debounce, and implements drop or replace at operation start. A generation token prevents old responses or cleanup from overwriting a newer operation. Cancellation clears timers and aborts the client signal. The forms pending helper temporarily disables native and externally associated submitters, preserves original disabled states, and guards aria affordance restoration by token. A client abort cannot undo a mutation already accepted by the server. T038 connects this controller to accepted action settlement and lifecycle commands.

Validation: typecheck, build, 117 unit tests including six action concurrency cases, and six pending-affordance browser cases across Chromium, Firefox, and WebKit.
