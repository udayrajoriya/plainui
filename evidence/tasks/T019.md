# T019 — Conditional template chains

Completed 14 October 2026. Commit: recorded in Git history as the T019 commit.

Conditional grouping accepts adjacent `ui-if`/`ui-else-if`/`ui-else` templates across whitespace and comments, rejects orphan and invalid branches, and creates an anchored chain owner. Conditions evaluate in order and stop at the first truthy branch. A changed selection disposes the prior branch owner, clones the selected source template, compiles its local declarations and bindings, and inserts an owned range. Unchanged selection retains the same DOM and local state. Expression-limit failures preserve the previous branch; ordinary expression errors diagnose and evaluate as false. State path dependencies schedule later structure passes.

Validation: `typecheck`, `build`, 53 unit tests, and six conditional browser cases across Chromium, Firefox, and WebKit. Cases cover whitespace grouping, same-branch identity, state-driven branch replacement, old DOM disposal, and else fallback.
