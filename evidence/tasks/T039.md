# T039 — Text and numeric model controls

Completed 15 October 2026. Commit: recorded in Git history as the T039 commit.

The runtime binds writable lexical paths to text, textarea, number, and range controls. Text composition commits once at composition end; external state changes preserve the active caret and dispatch no synthetic input. Numeric controls map empty input to null, retain the model during bad input, and clear only their own validity message. Unsupported controls and file inputs produce diagnostics, and input type changes safely replace the adapter.

Validation: typecheck, package boundaries, and 15 focused browser cases across Chromium, Firefox, and WebKit. The browser cases cover model writes, IME, empty and invalid numbers, caret, no synthetic events, and file-type rejection/recovery.
