# T030 — Attempt retries and cancellation

Completed 15 October 2026. Commit: recorded in Git history as the T030 commit.

GET retry counts 0–3 now produce at most `1 + retry` attempts. Only raw network failures, transport timeouts, and HTTP 502/503/504 retry, after exact 500/1000/2000 ms backoffs. Each attempt uses a new controller and deadline. The owner signal cancels a pending backoff immediately; epoch/generation liveness is checked before attempts and after delays. Mutations never replay. Adapter error hooks receive only the final accepted failure, with response metadata retained for HTTP and parse errors.

Validation: typecheck, build, 87 unit tests, two foundation integration tests, and five focused retry cases covering the four-attempt timeline, no-retry failures, backoff cancellation, per-attempt timeout, and mutation single-attempt behavior. The foundation browser suite previously passed 117 cases across Chromium, Firefox, and WebKit; T030 changes only the data transport.
