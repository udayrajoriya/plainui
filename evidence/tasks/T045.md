# T045 — Request accessibility and form lifecycle

Completed 16 October 2026. Commit: recorded in Git history as the T045 commit.

Resource templates claim busy state on their nearest parent; actions claim it on their own host. A shared per-element counter keeps `aria-busy` until every concurrent request settles, then restores the preexisting value only if still owned. Pending forms disable all form-associated submit controls, including external buttons, after submission data has been captured. Failure preserves models and files. Success leaves controls intact unless an authored reset command runs.

Validation: typecheck, existing action/resource browser suites (57 cases), and nine new browser cases across Chromium, Firefox, and WebKit for shared busy state, busy restoration, external submit buttons, failure preservation, success without reset, and explicit success reset.
