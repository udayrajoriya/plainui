# T033 — Resource records and load state machine

Completed 15 October 2026. Commit: recorded in Git history as the T033 commit.

Resource templates now register read-only records before bindings run. The data resource root evaluates URL, query, and header dependencies, prepares requests, shares compatible GETs, and publishes generation-guarded idle/loading/success/error snapshots. Key changes clear the prior entity, same-key refresh keeps successful data visible, failures remain normalized, cancellation restores the last settled snapshot, and lifecycle events run after the binding flush. The runtime composition seam now supplies the resource root to the app scaffold.

Validation: typecheck, boundary check, build, 104 unit tests, and 129 browser tests across Chromium, Firefox, and WebKit, including resource key switching, shared GET failures, and DOM-before-lifecycle ordering.
