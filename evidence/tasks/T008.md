# T008 — Safe JSON and writable paths

Completed 14 October 2026. Commit: recorded in Git history as the T008 commit.

The JSON boundary traverses iteratively with an active ancestry set. It rejects cycles while copying repeated noncyclic references independently, reads property descriptors without invoking getters, rejects symbols, custom prototypes, nonenumerable object properties, forbidden keys and nonfinite numbers, and uses null-prototype records. Undefined normalizes to null. Sparse-array holes are rejected by default and normalize to null only through the explicit JS-boundary helper. Clones and public snapshots are detached; snapshot freezing is iterative.

Writable paths have source spans and fixed dot/quoted-key/integer-index segments. They reject computed paths, forbidden keys, array growth, missing intermediate containers, and writes to read-only roots. Updates copy only containers along the path, retain sibling identity, and return changed prefixes. Read parsing permits array length, while writable parsing rejects it.

Validation: `typecheck`, `build`, and 25 unit tests pass with Node 24.21.0. A 20,000-level array normalizes and freezes without recursion overflow. Acceptance IDs include `json.pollution`, `json.getter`, `json.cycle`, `json.class`, `json.undefined`, `path.sibling-sharing`, `path.readonly`, `path.missing-container`, and snapshot mutation.
