# T014 — Derived values and flush scheduling

Completed 14 October 2026. Commit: recorded in Git history as the T014 commit.

The per-root scheduler deduplicates jobs, runs derived, structure, bindings, accessibility, and afterFlush phases in order, routes in-flush writes to a later pass, skips dead owners, and limits a single flush to 100 passes with one `UPDATE_LOOP` diagnostic. `afterFlush` returns an idempotent cancellation function. A derived graph traverses dependencies before readers, detects and disables cycle members, preserves values on expression limits, and publishes null on normal type errors.

Validation: `typecheck`; 51 unit tests. New cases cover phase order, cancellation, dead-owner skipping, the 100-pass limit, other-root independence, multi-hop evaluation, partial cycle handling, and limit preservation.
