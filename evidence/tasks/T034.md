# T034 — Resource activation and freshness

Completed 15 October 2026. Commit: recorded in Git history as the T034 commit.

Manual resources now resolve identity without fetching until explicit refresh. Visible resources observe their containing element, load on the first intersection, then act as automatic resources; observation is disconnected on first visibility or disposal. Invalid targets diagnose. A shared root timer marks positive-TTL records stale at the earliest deadline without fetching merely because time passed. Explicit refresh works before a visible resource intersects.

Validation: typecheck, build, 106 unit tests, and focused resource browser tests across Chromium, Firefox, and WebKit, including manual, visible, hidden explicit refresh, disposal, and TTL cases.
