# T040 — Checkbox, radio, and select models

Completed 15 October 2026. Commit: recorded in Git history as the T040 commit.

Checkbox models require booleans and synchronize `checked` on change. Radio models require strings, synchronize within native name/form ownership, and diagnose conflicting bound paths in a group. Select models support single strings and multiple string arrays in DOM option order, including unmatched and empty selections. Option mutation resynchronizes selection; model registrations are owner-scoped and indexed by form for later reset snapshots.

Validation: typecheck and nine focused browser cases across Chromium, Firefox, and WebKit for checkbox type enforcement, radio synchronization/conflicts, and select ordering/dynamic options.
