# T036 — Action declarations and records

Completed 15 October 2026. Commit: recorded in Git history as the T036 commit.

The action compiler now validates one request method, default or explicit trigger, request expressions, response mode, form fallback, encoding, concurrency, debounce, and lifecycle command syntax before activation. It rejects duplicate same-trigger handlers, GET bodies, incompatible HTML/JSON options, missing fragment support, and invalid native form fallback. Named actions register read-only idle cells in the enclosing scope; every action gets its own `$action` context, including unnamed actions. Compiled plans are retained for the T037 trigger pipeline.

Validation: typecheck, build, 111 unit tests, and nine focused browser tests across Chromium, Firefox, and WebKit covering named/unnamed records and name collisions.
