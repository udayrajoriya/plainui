# T041 — Successful-control form serialization

Completed 15 October 2026. Commit: recorded in Git history as the T041 commit.

The serializer walks native form-associated controls in document order, including external controls and the actual submitter. It excludes disabled controls, unchecked choices, and non-submitting buttons; image submitters include captured coordinates. JSON groups repeated literal names and converts only numeric controls; form encoding keeps native strings. JSON rejects any file, while multipart excludes unselected placeholders and retains explicitly selected empty files. GET query merging replaces same-name URL pairs. The native `FormData(form, submitter)` overload is feature-tested for compatibility decisions.

Validation: typecheck, boundaries, and twelve browser cases across Chromium, Firefox, and WebKit, including external order, disabled fieldsets, files, repeated names, image coordinates, and query replacement.
