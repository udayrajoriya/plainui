# T010 — Evaluator and built-in formatters

Completed 14 October 2026. Commit: recorded in Git history as the T010 commit.

The evaluator reads through an injected lexical interface, records exact property-path dependencies, returns nonfatal missing-value state, and reports failures out of band with a code and source span. It uses own-property object lookup, null chaining, array indices/length, computed-key rejection, identity equality, precise truthiness, typed arithmetic and ordering, finite-result checks, and short-circuit boolean/coalescing/ternary behavior. One `EvaluationBudget` counts AST nodes and property reads across an invocation and stops before step 10001. No generated JavaScript is evaluated.

Built-ins `len`, `json`, `number`, `currency`, and `date` validate inputs. Date-only strings validate actual Gregorian days and format in UTC to preserve their calendar date; explicit-offset timestamps and epoch milliseconds format in the configured zone. A 128-entry LRU caches Intl instances. Custom formatter results normalize at the JSON boundary; promises and writes through the formatter guard fail.

Validation: `typecheck`, `build`, 40 unit tests, and the no-eval CSP browser test in Chromium, Firefox, and WebKit pass with Node 24.21.0. Acceptance IDs `eval.null-missing`, `eval.identity`, `eval.no-coercion`, `eval.short-circuit`, `eval.step-limit`, `format.leap-day`, `format.date-zone`, `format.bad-currency`, and `format.async-rejected` pass. The CSP test runs the parser/evaluator bundle from an external script with `script-src 'self'` and no unsafe-eval.
