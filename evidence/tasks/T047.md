# T047 — Inline component definitions

Completed 16 October 2026. Commit: recorded in Git history as the T047 commit.

Each app root discovers inline definition templates before activation, including definitions after their hosts. The root-local registry validates custom-element-compatible names, collisions, prop schemas/defaults, per-instance state source, duplicate slots, and static IDs. It stores an immutable clone source and reusable node plan with static reference metadata; definition templates are excluded from ordinary app state compilation. Invalid names affect only their own definitions, and separate roots may reuse a name. The registry freezes at mount readiness and is disposed with the root.

Validation: typecheck, build, 122 unit tests, and twelve focused browser cases across Chromium, Firefox, and WebKit.
