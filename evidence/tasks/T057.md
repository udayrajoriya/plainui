# T057 — Indexed history and canceled traversal restoration

Completed 16 October 2026. Commit: recorded in Git history as the T057 commit.

Router history adopts the initial entry with a merged `__plainui` state record, saves departure scroll, pushes exactly one indexed destination, and ignores exact-URL navigations. Traversal owns manual scroll restoration, deduplicates matching popstate/hashchange delivery, runs guards against the already changed URL, corrects a canceled known traversal with one `history.go(delta)`, suppresses that correction event, and delegates unknown entries to document navigation without guessing an index. Unmount removes listeners and restores the prior scroll-restoration mode.

Validation: browser history tests across Chromium, Firefox, and WebKit cover state preservation, push counts, canceled back correction, correction suppression, unknown entries, hash deduplication, and restoration cleanup.
