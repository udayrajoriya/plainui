# T043 — Explicit form reset snapshots

Completed 16 October 2026. Commit: recorded in Git history as the T043 commit.

Each modeled form records its initial state after model activation, deduplicating radio paths and retaining the broadest overlapping path. Native reset events restore only captured model paths after the browser's own reset step; canceled events leave state untouched. The `reset(ref)` command resolves a lexical form reference and calls the same native reset path. File inputs remain browser-owned, and removal or remount disposes and recaptures snapshots.

Validation: typecheck and nine browser cases across Chromium, Firefox, and WebKit for native and command reset, unrelated state, radio deduplication, canceled reset, file behavior, and remount defaults.
