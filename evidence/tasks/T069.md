# T069 — Behavior factories and widget ownership

Completed 16 October 2026. Commit: recorded in Git history as the T069 commit.

`ui-use` now compiles ordered unique registered behavior names and `ui-options` as a frozen copied JSON object. Behavior jobs run in their own scheduler phase after bindings and before deferred resource activation. Each behavior receives its element, options, scoped API, and owner signal. Invalid asynchronous or non-cleanup returns fail locally; later-factory failure aborts the behavior owner and runs prior cleanups once in reverse order while the host remains connected. The scoped API checks lifetime for state, refs, events, refresh, batches, and cancellable after-flush work, diagnosing rejected post-disposal writes. Existing compiler traversal preserves `ui-ignore` widget subtrees.

Validation: all six named behavior cases passed in Chromium, Firefox, and WebKit (18 passing cases), and the workspace TypeScript check passed.
