# T006 — Configuration and diagnostics

Completed 14 October 2026. Commit: recorded in Git history as the T006 commit.

`resolveConfiguration` selects exactly one inert JSON script by document ID, validates nested fields, merges defaults/block/programmatic options (including case-insensitive headers), resolves document-based URL defaults and allowed origins, canonicalizes locale, checks time zone and CSRF names, and returns frozen options. It stores no CSRF token. Invalid configuration throws typed `CONFIG_INVALID`.

The diagnostic bus supports subscription before mount and idempotent unsubscription. It emits static code/severity/message records, safe directive and span metadata, redacted location/correlation values, and isolates listener exceptions. The inspector maintains numeric allocation/release counters without owner references and gates snapshots on debug mode.

Files: `packages/core/src/config.ts`, `packages/core/src/diagnostics/{codes,emit,redact,inspector}.ts`, core exports, unit and browser tests, task records.

Validation: `typecheck`, `build`, 20 unit tests, and the three-engine configuration browser test pass. The full browser suite had 33 passing tests and only the new config test failed before adding a document base URL to its `about:blank` test page; the corrected test passes in Chromium, Firefox, and WebKit. Acceptance IDs: `config.precedence`, `config.unknown-nested`, `config.bad-json`, `config.locale-zone`, `diagnostic.redaction`, `diagnostic.listener-throws`, `inspector.disabled`, `inspector.zero`.
