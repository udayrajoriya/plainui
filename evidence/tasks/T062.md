# T062 — Exact fragment sanitizer policy

Completed 16 October 2026. Commit: recorded in Git history as the T062 commit.

The fragments package now owns a private DOMPurify instance per document with reference-counted release. It uses the exact HTML tag and attribute policy, drops executable/embedded subtrees, unwraps other unsupported elements, strips all framework directives by default, and permits only the C12 enhanced directives, registered component tags, and declared prop attributes when explicitly authorized. URL sinks are revalidated after sanitation; form actions are same-origin; `_blank` receives `noopener noreferrer`; and a second traversal validates namespaces, attributes, nested templates, and registered custom elements. Results contain a DOM fragment and count-only report, never raw input.

Validation: twelve browser cases across Chromium, Firefox, and WebKit cover exact tags/attributes, subtree dropping versus unwrapping, data-ui bypasses, encoded executable URLs, blank rel, form origin, enhanced components, and namespace confusion.
