# T068 — Fragment security regression suite

Completed 16 October 2026. Commit: recorded in Git history as the T068 commit.

The security corpus covers every allowlisted fragment tag and attribute plus dynamic ARIA/data attributes. Adversarial fixtures exercise executable subtrees, inline handlers and sink attributes, encoded/mixed/control-character JavaScript URLs, SVG/MathML confusion, metadata and embedded content, case and namespace directive bypasses, unregistered custom elements, nested templates, DOM-clobbering names, mutation-XSS shapes, and table foster parenting. Runtime cases verify same-origin sanitation, failed-HTTP preservation, response trust isolation, detached late-target rejection, and sanitized nested component/slot DOM.

The suite ran under an external-script-only CSP with execution state and network beacons instrumented. Chromium, Firefox, and WebKit passed all 15 cases with zero executable effects and zero forbidden beacons. Exact DOMPurify version/integrity, policy and corpus SHA-256 hashes, browser revisions, named cases, and outcomes are recorded in `evidence/security/fragment-policy.json`.
