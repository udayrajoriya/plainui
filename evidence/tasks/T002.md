# T002 — Initialize the workspace and pin tools

Completed 11 October 2026. The existing Git repository was reused; no remote was created.

The root manifest pins Node 24.21.0 via `.node-version`, pnpm 12.10.1 via `packageManager`, and all C01 direct npm dependencies as exact versions. Eleven private packages implement the C02 workspace layout. `pnpm-lock.yaml` contains the complete resolved graph. `pnpm-workspace.yaml` enforces exact saves, the Node engine, and frozen installs, and grants the esbuild install script explicitly; all other dependency build scripts remain unapproved by default. Browser code uses a strict TypeScript base configuration with no ambient Node types.

The initial unbounded Vitest peer selected Vite 8.3.4. Its Rolldown native binding was absent after the Windows pnpm install, so Vitest could not start. C01 now explicitly pins Vite 7.3.7, the latest 7.x version reported by the npm registry during T002. Vitest 5.0.3 then passed on Windows and Linux. This was an exact peer pin added during the compatibility gate, not a change to the prescribed Vitest version.

The C01 amendment was copied into decision record 0001 and proposed revision A001, and their digests were updated in the T001 baseline manifest with the original contract hash retained as history. `python scripts/spec_baseline.py --check` passes; the supplied DOCX files and their transcriptions remain unchanged.

`scripts/workspace.mjs` registers all twelve planned task names as cross-platform Node commands. T002 implements `typecheck`, `test:unit`, `test:browser`, and a temporary smoke `build`; the remaining names exit nonzero with the plan task that will implement them. T003 will replace the smoke build with distribution entries.

Verification on Windows x64 and Ubuntu 26.04 x64 under WSL2 used Node 24.21.0 and pnpm 12.10.1. Both platforms passed TypeScript compilation, one Vitest assertion, esbuild classic IIFE and ESM builds, and the Playwright page in Chromium, Firefox, and WebKit. On Windows, `pnpm clean --yes` removed `node_modules`, then `pnpm install --frozen-lockfile` succeeded. A copy of the manifest changed Vitest 5.0.3 to 5.0.2; frozen install rejected it with `ERR_PNPM_OUTDATED_LOCKFILE`. Node 20.13.1 was rejected by engine enforcement. Linux installed the final lockfile with `--frozen-lockfile` and ran the same scripts. These are toolchain smoke checks, not framework conformance or browser-release qualification.
