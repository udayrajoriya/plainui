# T038 — Action settlement and lifecycle handlers

Completed 15 October 2026. Commit: recorded in Git history as the T038 commit.

Compiled actions now activate DOM triggers and use the request pipeline. Accepted results publish pending/status/data/error before handlers. Successful mutations resolve lexical invalidation names, deduplicate final cache keys, advance invalidation generations, and schedule active resource revalidation. After the binding flush, success or error runs, followed by protected finally; cancellation only runs finally while its owner remains active. Lifecycle command scopes expose `$result`, `$error`, `$action`, and a safe event snapshot. A bad command or invalidate name diagnoses locally without changing an accepted HTTP success.

Validation: typecheck, build, 122 unit tests, and action/resource browser tests across Chromium, Firefox, and WebKit, including shared-key invalidation, DOM-before-handler ordering, error/finally, and bad-name isolation.
