# T042 — Native form validation and submit interception

Completed 16 October 2026. Commit: recorded in Git history as the T042 commit.

Enhanced forms listen to the native submit event and use its actual submitter. Native validity is checked first, respecting `novalidate` and `formnovalidate`; invalid controls receive focus and no request starts. A valid submit captures URL, headers, controls, files, and submitter synchronously before debounce. Serialization failure becomes a local action error without transmission or native replay. Rejected enhancement leaves the form's native behavior intact. Programmatic `form.submit()` bypasses submit events by browser design; use `requestSubmit()` for enhanced submission.

Validation: typecheck, build, existing action browser cases, and 15 submit browser cases across Chromium, Firefox, and WebKit. Cases cover required validation, validation overrides, requestSubmit, Enter, actual submitter, debounce snapshot, local preparation error, and invalid enhancement configuration.
