# T009 — Tokenizer and Pratt expression parser

Completed 14 October 2026. Commit: recorded in Git history as the T009 commit.

The tokenizer enforces a 16 KiB UTF-8 source limit before scanning and records UTF-16 spans for exact decimal numbers, strings, identifiers, operators, and punctuation. The parser implements the C05 precedence table, left-associative binary operations, right-associative ternary, grouped expressions, arrays, quoted-key objects, named formatter calls, member and index access. Group nodes preserve parenthesization so ungrouped `??`/`&&`/`||` mixes fail. Unsupported executable syntax, duplicate object keys, trailing commas and leftover tokens fail with bounded parse diagnostics. AST depth is checked independently of guarded parser recursion, including member chains. The 512-entry grammar/mode/source LRU freezes successful ASTs and can cache invalid parses without root state.

Validation: `typecheck`, `build`, and 32 unit tests pass with Node 24.21.0. Acceptance IDs `parse.precedence` (all binary operator pairs), `parse.nullish-mix`, `parse.unicode-bytes`, `parse.depth-128-129`, `parse.strings`, `parse.no-executable-syntax` pass. Fast-check ran 2,000 arbitrary strings with seed 20261014 and observed only ASTs or bounded `ExpressionError`s.
