# T023 — Core command execution

Completed 15 October 2026. Commit: recorded in Git history as the T023 commit.

Event directives now invoke sequential commands against the lexical scope. Built-ins cover state writes, event emission, focus after flush, refresh, same-origin navigation, and optional form/UI services. `reset('formRef')` requires a form service; it is distinct from `app.resetSession()`. Custom commands receive a scoped API and detached event snapshot. Command failures stop that handler; disposed owners cannot continue commands or write through retained scope APIs. Refs are registered for initial, structural, and externally inserted content.

Validation: typecheck, build, 58 unit tests, and nine command browser cases across Chromium, Firefox, and WebKit.
