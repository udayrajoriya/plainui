# T048 — Component import graph

Completed 16 October 2026. Commit: recorded in Git history as the T048 commit.

Component imports resolve relative to the document or importing file, enforce same-origin HTTP(S) URLs without userinfo, strip fragments, and share one root-local load per canonical URL. Each fetch uses same-origin credentials, redirect rejection, the app timeout, and the root abort signal. The inert HTML parser accepts only definition/import templates and rejects script/style at every template depth. DFS loads dependencies before definitions, diagnoses cycles with query-redacted pathname chains, and retains failures so imports do not repeatedly fetch. App readiness waits for the graph while independent bindings continue rendering.

Validation: typecheck, build, and eighteen import browser cases across Chromium, Firefox, and WebKit, including nested relative paths, deduplication, cycles, cross-origin policy, an actual HTTP redirect, nested script rejection, timeout, and unmount.
