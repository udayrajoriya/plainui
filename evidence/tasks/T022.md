# T022 — Command parsing and event snapshots

Completed 15 October 2026. Commit: recorded in Git history as the T022 commit.

The command parser splits only top-level semicolons and commas, accepts exact-name calls with an optional final semicolon, parses `set`/`toggle` write paths separately, and rejects statements, empty interior commands, and nested effect calls. Event directives validate native/lifecycle names, modifiers, duplicates, and request-trigger collisions. Event snapshots contain only type, key, button, value, checked, and detached, frozen JSON detail; live DOM/Event references cannot enter a snapshot. Owner-bound listeners apply `.self` before synchronous prevent/stop and consume `.once` on the first eligible event. Each invocation receives one shared evaluation budget.

Validation: `typecheck`, `build`, 58 unit tests, and six browser handler/snapshot cases across Chromium, Firefox, and WebKit.
