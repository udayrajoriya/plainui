# T070 — Accessible native dialog commands

Completed 16 October 2026. Commit: recorded in Git history as the T070 commit.

The UI module now installs an app-owned UI command service without registering over core command names. Lexically resolved `open(ref)` and `close(ref)` commands delegate to a native-dialog controller. Opening requires a connected in-root `HTMLDialogElement`, `showModal`, and a nonempty `aria-label` or fully resolved nonempty `aria-labelledby` chain. The controller records the connected opener, relies on native modal focus and Escape/cancel behavior, restores a still-connected focusable opener after close, and closes/removes listeners without focus work on disposal. Invalid refs and dead controllers report local UI/owner diagnostics.

Validation: the seven named dialog cases plus an end-to-end built-in command-service case passed in Chromium, Firefox, and WebKit (24 passing cases). Keyboard Escape and prevented-cancel behavior were driven through Playwright. TypeScript passed.
