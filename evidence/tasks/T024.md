# T024 — Root and lexical public APIs

Completed 15 October 2026. Commit: recorded in Git history as the T024 commit.

The App exposes pre-mount extension registration, diagnostic subscriptions, debug inspection, app-scoped state access, resource refresh, session reset, navigation guard registration through an optional service, and lifecycle checks. App and lexical reads return detached frozen snapshots. `resetSession` preserves state per the specification; later data work will attach request cancellation and cache invalidation to its epoch. Public types cover scope, command, behavior, adapter, records, diagnostics, and module installation; a plain JavaScript usage example and compile-time positive/negative fixtures are included.

Validation: workspace typecheck, dedicated public API typecheck, build, 58 unit tests, and 12 browser cases across Chromium, Firefox, and WebKit.
