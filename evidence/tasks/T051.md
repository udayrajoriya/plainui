# T051 — Static ID and ARIA reference rewriting

Completed 16 October 2026. Commit: recorded in Git history as the T051 commit.

Each application root receives a document-wide serial and allocates monotonically increasing component instance serials. Static definition IDs are rewritten on cloned fragments before activation, with local `for`, `aria-labelledby`, `aria-describedby`, and `aria-controls` tokens following the generated IDs. External tokens, projected caller content, and dynamically bound ID/reference attributes remain authored values. Collision detection advances the complete instance serial, and a fragment can be rewritten only once.

Validation: typecheck and twelve browser cases across Chromium, Firefox, and WebKit, including accessible-name and label association assertions.
