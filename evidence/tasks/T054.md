# T054 — Route patterns and destination values

Completed 16 October 2026. Commit: recorded in Git history as the T054 commit.

Route compilation now validates literal, parameter, final catchall, and sole fallback patterns; normalizes trailing slashes; rejects duplicate or malformed parameter names and encoding; ranks candidates left-to-right; and rejects equal-specificity overlaps. Location parsing enforces origin and base-path boundaries in history and hash modes, decodes each segment once, preserves encoded slashes within one parameter, produces ordered query arrays, and freezes route records including the inner hash.

Validation: router unit tests and six browser cases across Chromium, Firefox, and WebKit cover ranking, ambiguity, malformed encoding, catchall-empty matching, query arrays, base boundaries, fallback selection, and declaration cardinality.
