# T021 — Mutation observation

Completed 15 October 2026. Commit: recorded in Git history as the T021 commit.

The root observer reconciles child and directive-attribute mutation records against a count-based transaction journal and final connectivity. Framework range insertions, moves, disposal, and cloak removal are journaled so later observer delivery does not remount them. App-authored elements compile under the nearest active owner and lexical scope; same-scope moves preserve ownership, while cross-scope moves dispose and recompile with defaults. Directive edits diagnose `DECLARATION_CHANGED` while keeping compiled behavior. Ignored descendants are skipped. External removals dispose owner boundaries, while ordinary child text changes only update the node index. Observation disconnects before root teardown.

Validation: `typecheck`, `build`, 55 unit tests, and 12 focused conditional, list, and observer browser cases across Chromium, Firefox, and WebKit. Cases cover authored additions, same/cross-scope moves, remove/reinsert, directive edits, ignored descendants, and framework range operations.
