# T005 — Shared conformance fixture runner

Completed 14 October 2026. Commit: recorded in Git history as the T005 commit.

The fixture format defines HTML/config/modules/registrations/storage/HTTP script, ordered steps, expected DOM/state/events/diagnostics/request counts, browser requirements, and teardown counts. The runner loads the same local distribution assets in classic and ESM mode, resets storage/history/server state, executes bounded steps, captures outcomes, and cancels held responses in `finally`. The local HTTP server uses two distinct loopback origins, named response barriers, chosen statuses/headers/bodies, redirects, socket closure, and unexpected-request reporting. The deterministic clock orders equal-deadline tasks and cancels pending work.

The current runtime is still a T003 scaffold: parity exercises module installation and build loading; full mount/state/request fixtures become executable as the corresponding runtime tasks land. `tests/fixtures/directive-coverage.json` now holds the T004 coverage index; `tests/fixtures/schema.json` is the conformance fixture format.

Validation: `typecheck`, `test:unit` (15 tests), and `test:conformance` (15 Playwright cases across Chromium, Firefox, WebKit) pass with Node 24.21.0. Acceptance IDs `harness.parity`, `harness.race`, `harness.leak`, and `harness.timeout` pass.
